材质调整
--------
文件夹：/Game/YU7/Lookdev/Materials
M_YU7_AutomotivePaint：参数化底漆 + Clear Coat；PigmentColor、EdgeTint、
ColorFlop、Metallic、BaseRoughness、CoatRoughness 可在 MI_Paint_* 调整。
颜色是作品艺术方案，不是小米官方配色或实测光谱。

M_YU7_ThinGlass：Thin Translucent。MI_Glass_Clear / Smoked 用于车窗；
MI_Glass_Roof 用于天幕；MI_Glass_Lens 用于灯罩。
TransmissionTint 控制透射吸收，Roughness 控制高光宽度，Specular 控制反射。
当前 Substrate 转换下 OpaqueLayerAmount=0，SurfaceCoverage=1；不要把根
Opacity 当成薄玻璃覆盖率，否则会变成不透明黑镜。此设置经实际渲染检查。

M_YU7_TrimMasked：保留原贴图 Alpha 遮罩，独立调整黑色塑料和窗框金属。
MI_Detail_Charcoal 修正出风口等深灰部位。原导入材质和网格未覆盖。

灯光调整
--------
Outliner 的 YU7/LookdevLights 下有 6 个 YU7_Light_* RectLight：
Key_Softbox 主柔光、Side_Strip 侧条光、Rear_Rim 后轮廓、Front_Fill 前补光、
Roof_Ribbon 顶条光、Backdrop_Wash 背景光。
5 个主体灯使用原创 T_SoftboxDiffuser 渐变，柔化反射边缘。
Beauty / Sculpted Contrast 记录这 6 盏灯的强度；修改灯光强度后，需要在
对应 Variant 的捕获属性里重新 Record，才能保存为该灯光方案。
主后期：固定 EV 区间、较低 Bloom、无运动模糊、高质量 Lumen 反射。

UE 5.8 稳定性处理
-----------------
制作中发现：Variant Manager 捕获 Blueprint 构造组件的材质/灯光后，
跨帧切换可能在引擎 HasValidResolve 中遇到失效组件缓存并崩溃。
因此 21 个参与切换的分件采用原生 StaticMeshActor，附着在 YU7_Hero 下；
相应 BP 组件只在当前地图隐藏并关闭阴影。其余 100 个部件仍由 BP 显示。
原 BP 的 121 个组件和源网格全部保留，不重复绘制，不改几何或法线。
6 盏活动灯采用原生 RectLight；灯光 Blueprint 留在 Reference 下且已停用。
这是编辑器绑定层的替代方案，运行时仍可通过 Blueprint 使用 Variant Manager。
不要把这些变体重新绑定回 Blueprint 的构造组件；详见 DEV_HISTORY.md。

当前 UE 5.8 还有地图重载时的缓存限制：使用过变体后，不要只重载关卡
再继续使用内存中的同一 LVS。可正常保存并重开项目，或在 UE 的
Tools > Execute Python Script 运行项目 tools/ue_lookdev_reload.py：
它先保存、重新加载 LVS 资产清掉旧组件缓存，再加载 Studio_YU7。
该脚本仅服务编辑器工作流；运行时切换无需 Python。
